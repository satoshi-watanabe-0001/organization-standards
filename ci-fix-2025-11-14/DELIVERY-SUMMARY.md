### 🎯 対応した問題

- **問題**: 以前に修正した内容が元に戻されており、`${{ fromJSON() }}`がJavaScriptコード内で使用されている
- **影響**: `TypeError: Cannot read properties of undefined`エラーが発生し、CI実行が失敗する
- **修正**: 環境変数 + `JSON.parse()`アプローチに変更（3箇所）

### 修正パターン

#### ❌ 修正前
```yaml
- name: Validate PR description
  uses: actions/github-script@v7
  with:
    script: |
      const prInfo = ${{ fromJSON(steps['pr-info'].outputs.result) }};
```

#### ✅ 修正後
```yaml
- name: Validate PR description
  uses: actions/github-script@v7
  env:
    PR_INFO: ${{ steps['pr-info'].outputs.result }}
  with:
    script: |
      const prInfo = JSON.parse(process.env.PR_INFO);
```
